# Установка и запуск CRM на другом компьютере

Эта инструкция запускает текущую тестовую версию CRM: frontend + локальный dev API без PostgreSQL и Docker. Этого достаточно, чтобы открыть сайт, войти и протестировать интерфейс.

## 1. Что установить

1. Установите Node.js 22 LTS или новее: https://nodejs.org/en/download
2. Во время установки оставьте включенной опцию `Add to PATH`.
3. После установки закройте и заново откройте папку/терминал.

Docker и PostgreSQL для этого тестового запуска не нужны.

## 2. Как перенести проект

Скопируйте всю папку проекта `CRM` на другой компьютер. В папке должны быть, среди прочего:

- `install-crm.bat`
- `start-crm.bat`
- `stop-crm.bat`
- `.codex-dev-api.mjs`
- `.codex-run-dev-api.cmd`
- `.codex-run-web.cmd`
- `package.json`
- `package-lock.json`
- `apps`
- `packages`

Папку `node_modules` копировать необязательно: `install-crm.bat` установит зависимости заново.

## 3. Первая установка

В папке проекта запустите двойным кликом:

```text
install-crm.bat
```

Скрипт проверит Node.js/npm, создаст `.env`, установит зависимости и соберет общий пакет.

## 4. Запуск сайта

После установки запустите:

```text
start-crm.bat
```

Откроются два служебных окна:

- `Cosmetics CRM Dev API` - локальный API на `http://127.0.0.1:4000/api`
- `Cosmetics CRM Web` - frontend на `http://127.0.0.1:5173`

Сайт откроется автоматически. Если не открылся, перейдите вручную:

```text
http://127.0.0.1:5173
```

Данные для входа:

```text
login: admin
password: admin12345
```

## 5. Остановка

Когда закончите работу, запустите:

```text
stop-crm.bat
```

Он остановит процессы, которые слушают порты `4000` и `5173`.

## 6. Если что-то не запускается

- Если `install-crm.bat` пишет, что не найден `node` или `npm`, переустановите Node.js и проверьте опцию `Add to PATH`.
- Если порт `4000` или `5173` занят другой программой, закройте ее или запустите `stop-crm.bat`.
- Если `npm install` не проходит, проверьте интернет-соединение и повторите запуск `install-crm.bat`.

Важно: текущий dev API хранит данные в памяти. После остановки API созданные во время теста клиенты, заказы и товары сбросятся. Для постоянного хранения данных нужна полноценная версия backend с PostgreSQL.
